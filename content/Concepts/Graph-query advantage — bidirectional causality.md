# Graph-query advantage — bidirectional causality

From [[05 Ontology relationship model]], section 5.2 (Causal evidence pattern).

> [!tip] Graph-query advantage
> This structure lets the system answer both directions: "What caused similar cold shuts?" and "Which failure modes could this current temperature/ladle-wait pattern precede?" It also lets the answer show supporting and contradicting evidence.

See also: [[Causal evidence pattern]] section in [[05 Ontology relationship model]], [[supportsCause]], [[contradictsCause]], [[causedBy]].
