# Semantic layers L0-L7

From [[01 Executive recommendation]], section 1.2 ("The minimum semantic layers"). The Enterprise Brain is organized as layered commitments, each with a primary standards alignment.

| Layer | Scope | Primary alignment |
|---|---|---|
| L0 - Formal semantic core | Entity, physical object, information object, process type, process execution, event, state, role, quality, disposition, evidence, constraint, objective and risk. | IOF Core, OWL 2, W3C Time |
| L1 - Controlled reference data | Names, codes, broader/narrower categories, units, properties and external mappings. | SKOS, IEC 61360 / IEC CDD, ECLASS, QUDT |
| L2 - Enterprise and asset identity | Enterprise/site/area/line/work cell; functional/product/location/type aspects; assets and submodels. | ISA-95, IEC 81346, IEC 62832, AAS, AutomationML |
| L3 - Operations and procedure | Process segments, resource requirements, schedules/performance, recipe/procedure/operation/phase. | IEC 62264, IEC 61512 |
| L4 - Observations and phenomena | Sensors, observations, samples, results, states, symptoms, anomalies, failures and causal evidence. | SOSA/SSN, ISO 13374, ISO 13379, ISO 14224 |
| L5 - Foundry domain | Materials, heats, sand, cores, molds, pours, castings, defects, microstructure, routes and genealogy. | ISO cast-iron / casting-imperfection standards + plant vocabulary |
| L6 - Business and value | SIOP, traceability, inventory, finance, KPIs, benefit cases, ESG and risk. | SCOR, EPCIS, ISO 22400, XBRL GL, ISO 14001/50001/45001 |
| L7 - Knowledge and decision | Documents, assertions, evidence, guidance, recommendations, decisions, actions, outcomes, feedback and governance. | PROV-O, SHACL, ISO/IEC 42001, NIST AI RMF, IEC 62443 |

See also: [[01 Executive recommendation]], [[02 Standards architecture and crosswalk]], [[Modules]].
